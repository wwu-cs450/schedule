# User Stories

- As a user, I want to make a schedule for a whole year or a specific quarter so that I don't have to think about it
- As a user, I want to upload the classes I have already taken so that class suggestions avoid the classes I already took
- As a user, I want to tell the app that I like a certain professor, so the app will recommend a class taught by the professor
- As a user, I want to tell the app that I don’t like a certain professor, so the app will recommend a class taught by the professor
- As a user, I want to tell the app that I like taking a class at a certain time, so the app will recommend a class taught at the time
- As a user, I would like to select the classes I must take first, then auto pick the rest of the classes
- As a user, I want to specify how many credits I want to take in a specific quarter so that th classes recommended do not exceed the credit limit
- As a user, I want to specify whether I am a 4-year or 5-year student (for engineering), so that additional elective classes are suggested
- As a user, I want to be able to build the schedule from my phone
- As a user, I want to be able to speak with the AI instead of type out my requests, because I'm currently unable to use the keyboard
- As a user, I would like to use my WWU account to log into the app so that my progress is saved across devices
- As a user, I want to be able to specify my major and have the AI know my bulletin/guidebook requirements, so I dont have to check over it myself
- As a user, I want my specifications done through the AI chat to reflect on the All Classes window with all the appropriate filters put on them, so that I can look through all the classes  in a organized manner without having to manually put the filters on myself
- As a user I want to be able to specify secondary majors I maybe interested in and have the AI know my bulletin/guidebook requirements so it can suggest classes to take if I decided to pursue them.
