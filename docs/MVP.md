# Minimum Viable Product  
#### There should be the AI chat bot (ONLY INFORMATIONAL RN)
- User should be able to find AI chat bot within one click on the website
- Window to AI chat bot loads properly when opened
- The website has to work properly on mobile and have the chat bot accessible there too
- AI chat bot should be able to properly work and reply to user's messages


#### The AI chat bot should be aware of all classes available 
- User should be able to ask about any class available in WWU and have the AI report back accurate information/not hallucinate imaginary classes (only work from real data)
- When a user asks about a class that doesn't exist, AI chat bot should not hallucinate info about it and instead deny it exists
- When testing if the AI knows a class, the AI should also be aware of how many credits it has or when it's available

### The AI chat bot should be able to access the transcript you submit  
- When asked about the transcript by the user, AI chat bot gives accurate data
- AI chat bot should not suggest classes you already took
- If there is no transcript provided, AI chat bot should not reference any data regarding the user's past classes

### The AI chat bot should be aware of the CS bulletin so that it know all the core requirements needed of a student  
- When user asks about a class, AI should know if it is relevant or not to their major
- Once given suggestions by the chat bot, users must be able to ask for adjustments and have the AI accommodate them
- AI chat bot should not hallucinate any other major or bulletin outside of what is in its data
